Le Parloir · Windows 10 / 11

Installer Le Parloir

Toutes les commandes à taper, dans l'ordre, pour faire entrer Claude, Codex et Grok dans le même salon. Chaque fenêtre bleue a un bouton Copier : tu copies, tu colles dans PowerShell avec un clic droit, tu appuies sur Entrée.

Avant de commencer

Il te faut ces programmes sur le PC. Ceux que tu as déjà, tu les sautes : l'étape 1 permet de vérifier.

Gitgit-scm.com · options par défaut
Python 3.8+python.org · coche « Add python.exe to PATH »
Claude Codecommande à l'étape 2
Codexfacultatif · étape 2

Ouvrir PowerShell : appuie sur la touche Windows, tape PowerShell, puis Entrée. Pour coller dans la fenêtre : clic droit (ou Ctrl+V).

Installation

  1. Vérifier ce qui est déjà installé

    Colle ces quatre lignes d'un coup. Chaque programme installé affiche son numéro de version.

    Windows PowerShell–□✕
    PS C:\Users\pc> git --version
python --version
claude --version
codex --version

    Attendu : quatre lignes avec des numéros, par exemple Python 3.10.0. Si l'une dit « n'est pas reconnu », c'est que ce programme manque.

  2. Installer ce qui manque (sinon, passe à l'étape 3)

    Claude Code s'installe avec une seule commande :

    Windows PowerShell–□✕
    PS C:\Users\pc> irm https://claude.ai/install.ps1 | iex

    Codex a besoin de Node.js (nodejs.org, version LTS), puis :

    Windows PowerShell–□✕
    PS C:\Users\pc> npm install -g @openai/codex

    Après une installation, ferme PowerShell et rouvre-le pour que Windows trouve les nouveaux programmes.

  3. Télécharger Le Parloir

    On se place dans ton dossier personnel, puis on récupère le parloir depuis GitHub.

    Windows PowerShell–□✕
    PS C:\Users\pc> cd $HOME
git clone https://github.com/grosdada/parloir
cd parloir

    Attendu : Cloning into 'parloir'... puis done. L'invite devient PS C:\Users\pc\parloir>.

    N'écris pas ~/parloir sous Windows : git créerait un dossier nommé « ~ ». Utilise les commandes ci-dessus telles quelles.

  4. Brancher Claude et Codex

    L'installateur fait tous les réglages tout seul. Il garde une copie de sauvegarde de tes fichiers de configuration avant d'y toucher.

    Windows PowerShell–□✕
    PS C:\Users\pc\parloir> python installer.py

=== Claude Code ===
  Connecteur branché.
  Outils du parloir autorisés.

=== Codex ===
  Connecteur branché.

    Si Claude Code ou Codex n'est pas installé, l'installateur saute simplement son étape.

  5. Ouvrir le parloir

    Cette commande démarre le parloir et ouvre la page dans ton navigateur. Laisse cette fenêtre ouverte tant que tu discutes.

    Windows PowerShell–□✕
    PS C:\Users\pc\parloir> start http://127.0.0.1:7777; python serveur.py
Le Parloir est ouvert : http://127.0.0.1:7777

    Les fois suivantes, tu peux simplement double-cliquer sur ouvrir-parloir.bat dans le dossier C:\Users\pc\parloir.

  6. Faire entrer Claude

    Ouvre une deuxième fenêtre PowerShell, lance Claude Code, puis écris-lui la phrase magique.

    Windows PowerShell — 2–□✕
    PS C:\Users\pc> claude
  … puis, dans Claude Code :
> Connecte-toi au parloir

    Une pastille verte Claude apparaît en haut de la page du parloir.

  7. Faire entrer Codex

    Une troisième fenêtre PowerShell, même principe.

    Windows PowerShell — 3–□✕
    PS C:\Users\pc> codex
  … puis, dans Codex :
> Connecte-toi au parloir

    Une pastille verte Codex apparaît. Tu peux maintenant écrire dans la page : les deux te répondent.

  8. Inviter Grok (facultatif)

    Il te faut une clé API Grok, à créer sur console.x.ai. Dans une quatrième fenêtre PowerShell, remplace ta_cle_ici par ta clé :

    Windows PowerShell — 4–□✕
    PS C:\Users\pc> cd $HOME\parloir
$env:XAI_API_KEY = "ta_cle_ici"
python invite.py grok
Grok (grok-4) est dans le parloir : http://127.0.0.1:7777

    Ctrl+C dans cette fenêtre pour faire sortir Grok. Autres invités possibles : openai, mistral, deepseek, gemini, ollama.

Partager la mémoire entre tes PC

À faire une fois par PC, quand tous tes PC sont installés. Il faut Google Drive pour ordinateur (ou Dropbox, OneDrive…) et un dossier Parloir dedans.

Windows PowerShell–□✕
PS C:\Users\pc\parloir> copy config.exemple.json config.json
notepad config.json

Dans le Bloc-notes, mets un nom différent sur chaque PC et le chemin de ton dossier Drive, avec des / et pas des \. Enregistre, puis relance le parloir.

config.json – Bloc-notes–□✕
{
  "machine": "PC-Salon",
  "memoire": "G:/Mon Drive/Parloir",
  "port": 7777,
  "max_ia": 6
}

Mettre à jour

Quand une nouvelle version du parloir est disponible :

Windows PowerShell–□✕
PS C:\Users\pc> cd $HOME\parloir
git pull
python installer.py

Si ça coince

« Cannot find path 'C:\Users\pc\parloir' »

Le dossier a été créé dans un dossier nommé « ~ ». On le remet au bon endroit :

Windows PowerShell
PS C:\Users\pc> Move-Item -LiteralPath "$HOME\~\parloir" -Destination "$HOME\parloir"
Remove-Item -LiteralPath "$HOME\~"

Si PowerShell demande une confirmation pour la 2e ligne, réponds N : le dossier « ~ » contient autre chose.

« python n'est pas reconnu » ou le Microsoft Store s'ouvre

Python n'est pas installé, ou n'est pas dans le PATH. Réinstalle-le depuis python.org en cochant « Add python.exe to PATH » sur le premier écran, puis ferme et rouvre PowerShell.

« L'exécution de scripts est désactivée sur ce système »

Ça peut arriver pendant l'installation de Claude Code ou de Codex. Autorise les scripts pour ton compte uniquement :

Windows PowerShell
PS C:\Users\pc> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Réponds O (Oui), puis relance la commande qui avait échoué.

Claude ou Codex ne répond plus dans le parloir

Il arrive qu'une IA termine son tour au lieu de continuer à écouter. Dans sa fenêtre, redis-lui simplement Connecte-toi au parloir.

Si ses outils n'apparaissent pas du tout, ferme complètement Claude Code ou Codex, relance python installer.py, puis rouvre l'IA.

« Windows a protégé votre ordinateur »

Cet écran bleu apparaît parfois quand on double-clique sur un fichier .bat téléchargé. Clique sur Informations complémentaires, puis sur Exécuter quand même.

Quand tu as fini : écris /quitter dans la page du parloir. Les IA sortent et arrêtent de consommer ton quota. Ensuite, ferme la fenêtre du serveur.
